# Zoup · 3D Interactive Magazine

基于 **Three.js + Vite** 构建的 3D 交互场景页。以「框内 · 荒芜」为主题，在起伏的草地上营造出一方缓慢而温柔的世界：老树下坐着一个人，身旁停着一辆复古自行车，远处有低模山丘、树林、白云与飞鸟，微风拂过草叶沙沙作响。

## 功能特性

- 程序化生成的自然场景：起伏地形、双层风动草地、低模碎石/灌木/野花
- 完整的手工 3D 模型：复古自行车（车架、辐条、链条、皮革座垫等）与树下人物（胶囊四肢、五官细节）
- 动态氛围：微风吹动的草叶与树叶、漂浮白云、盘旋飞鸟、丁达尔光束、浮尘与蒲公英粒子
- 交互体验：拖拽旋转 / 滚轮缩放 / 自动环绕视角；点击物体弹出详情面板
- 可交互对象提示：场景内 3D 木牌「COSTA DESIGN」与悬浮文字可作为杂志封面元素

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 构建工具 | Vite 8 |
| 3D 引擎 | Three.js |
| 语言 | JavaScript（ES Modules） |
| 样式 | 原生 CSS |

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm 10+

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认端口 5176，自动打开浏览器）
npm run dev

# 生产构建
npm run build

# 预览构建产物
npm run preview
```

## 交互说明

- **拖拽**：旋转视角
- **滚轮**：缩放（有远近边界，不允许穿入地面）
- **点击物体**：弹出详情面板，可查看场景元素的中英文案与标签
- **点击复古自行车**：让车轮转动起来

## 项目结构
